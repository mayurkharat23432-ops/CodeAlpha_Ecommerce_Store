# ShopEase — CodeAlpha Task 1 (E-commerce Store)

## Features
- Product listing and search
- Product details available through `/api/products/:id`
- Shopping cart saved in browser local storage
- Demo registration and login
- Checkout/order processing with stock updates
- Orders stored in `data.json`
- Responsive layout

## Requirements
- Node.js 18 or later
- Internet not required after dependencies are installed

## Run on Windows
1. Install Node.js from the official Node.js website.
2. Extract this folder somewhere such as `C:\CodeAlpha\EcommerceStore`.
3. Open the folder in VS Code.
4. Open Terminal > New Terminal.
5. Run `npm install`
6. Run `npm start`
7. Open `http://localhost:3001`

## Important
This is a learning/demo internship project. It stores demo passwords as plain text in a local JSON file and is NOT production-secure. Do not use real personal information or real passwords. For deployment, use password hashing, a real database, validation, sessions, CSRF protection, and HTTPS.
